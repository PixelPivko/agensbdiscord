# Канал-ловушка
Канал: 1562603037506142228. Настройки trap в config/config.yml.
После установки бот публикует предупреждение, закрепляет его при наличии права Manage Messages, выставляет предупреждение в теме. Только после этого обрабатывает новые сообщения. Историю не банит.
Любое новое сообщение участника, включая вложения и ветки, вызывает бан. Исключены собственные сообщения бота, вебхуки и системные события. Другие боты тоже могут быть забанены. Владелец и участники не ниже роли бота технически недоступны для бана; ошибка попадает в журнал.
Имена меняются примерно раз в час, проверка каждые 60 секунд. Счётчик успешных банов хранится в журнале SQLite, обновляется раз в минуту. После простоя нет серии переименований.
Боту нужны Ban Members, Manage Channels, View Channel, Send Messages, Read Message History и роль выше целей. При отсутствии прав ловушка не активируется. Предупреждение о принуждении — правило для ручной модерации, не автоматическое распознавание.
Установка BotHost: сохранить резервную копию data и config, заменить bot.py, cogs/, services/, добавить в свой guild config блок trap из приложенного config. Не заменять .env и data. Пересобрать/перезапустить. Существующие запреты boost сохраняются. Доступ пользователям к каналу автоматически не меняется.
Это локальное обновление: на хостинг не загружено, предупреждение на сервере появится после запуска обновлённого бота.
